Zwróć TYLKO zapytanie SQL bez żadnych komentarzy ani wyjaśnień, ani ozdobników markdown, czysty SQL.

Zapytanie musi być zoptymalizowane pod kątem wydajności - użyj najbardziej efektywnej metody łączenia tabel.

Znajdź DC_ID aktywnych datacenter (is_active = 1), których menadżerowie są nieaktywni (is_active = 0).

Wymagania optymalizacji:
- Zastosuj filtrowanie jak najwcześniej w zapytaniu
- Użyj najbardziej wydajnego typu JOIN
- Uwzględnij, że tabela users może być duża
