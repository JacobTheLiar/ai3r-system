# Nawigacja Robota - Znajdź Ścieżkę

Twoim zadaniem jest znalezienie poprawnej ścieżki, aby robot (R) dotarł do komputera (K).

Oto dokładna specyfikacja mapy 6x8:

ROBOT (R) znajduje się na pozycji [4,1]
KOMPUTER (K) znajduje się na pozycji [4,6]

DOKŁADNE POZYCJE PODŁOGI (_):
- [1,1], [1,3], [1,4], [1,5], [1,6]
- [2,1], [2,2], [2,3], [2,5], [2,6]
- [3,1], [3,3], [3,5], [3,6]
- [4,3], [4,4], [4,5]

WSZYSTKIE INNE pozycje to ŚCIANY (X), których nie można przekroczyć.

TWOJE ZADANIE:
1. Rozpocznij od pozycji [4,1]
2. Używaj tylko ruchów UP, DOWN, LEFT, RIGHT
3. Każdy ruch to przesunięcie o DOKŁADNIE JEDNO pole (góra, dół, lewo, prawo)
4. Możesz poruszać się tylko po pozycjach PODŁOGI wymienionych powyżej
5. Musisz dotrzeć do pozycji [4,6]

UWAGA: Robot NIE MOŻE przejść bezpośrednio w prawo z pozycji [4,1], ponieważ [4,2] to ŚCIANA.

Twoja odpowiedź MUSI mieć format:
{
"thinking": "Twoja szczegółowa analiza tutaj...",
"steps": "UP, DOWN, RIGHT, LEFT"
}
